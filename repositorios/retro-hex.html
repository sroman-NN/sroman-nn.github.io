Retro-HEX

This is just a small virtual toy for computer enthusiasts, or it can simply be used as a utility or whatever.

Although it does actually work a little.

It's a hex editor with a retro aesthetic, like CRT or CRT (Amber). These are separate versions, each with its own theme.

Simply type, and you can perform simple actions such as saving, creating a new file, or exiting using the shortcuts M + (function number), for example, M + 1 to select the exit button, then Enter to execute it. Although it doesn't have mouse support by design, the code is in the GitHub repository. However, it's also available in native copies with CatCheer. In any case, it already has mouse support; it's just disabled in the code.
