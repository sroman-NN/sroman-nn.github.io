Configuración e Integración de Samba (Linux a Windows)

Guía : Compartir carpetas de Linux a Windows con Samba

Si necesitás acceder a archivos alojados en tu servidor o PC con Linux desde una red local en Windows, Samba es el estándar definitivo[cite: 6]. Acá econtraras el paso a paso exacto para configurar los recursos compartidos, gestionar permisos y conectar Windows facilmente[cite: 6].

1. Configuración de Samba (Linux)

El archivo de configuración principal de Samba se encuentra en /etc/samba/smb.conf[cite: 6]. Para compartir una carpeta, debes añadir una sección al final del archivo con la siguiente estructura básica[cite: 6]:

este es solo un ejemplo yo tengo 3 carpetas ustedes pueden escoger solo una 
[documentos]
   path = /home/tuusuario/Documentos
   browseable = yes
   read only = no
   guest ok = no
   valid users = hilo

[dev]
   path = /home/tuusuario/dev
   browseable = yes
   read only = no
   guest ok = no
   valid users = hilo

[imagenes]
   path = /home/tuusuario/Imágenes
   browseable = yes
   read only = no
   guest ok = no
   valid users = hilo

Comandos útiles para gestionar Samba

  • Verificar errores en el archivo de configuración:[cite: 6] 
    testparm
  • Reiniciar el servicio (en sistemas basados en Debian):[cite: 6] 
    sudo systemctl restart smbd
  • Crear un usuario de Samba (necesario para que Windows pueda autenticarse):[cite: 6] 
    sudo smbpasswd -a tu_usuario
Dato Técnico: El usuario de Samba debe existir previamente como usuario del sistema operativo Linux para que smbpasswd pueda habilitarlo correctamente.

2. Cómo obtener la dirección IP o el nombre de red en Linux

Para conectarte desde otro equipo, necesitas conocer la dirección IP de tu máquina Linux[cite: 6]. Puedes obtenerla con los siguientes comandos[cite: 6]:

  • Ver la IP local:[cite: 6] 
    ip a

    (Busca la interfaz de red activa, por ejemplo eth0(ehternet) o wlan0(wireless), junto a la etiqueta inet)[cite: 6].

  • Ver el nombre del host (equipo):[cite: 6] 
    hostname

3. Cómo escribir la ruta de conexión en Windows

Una vez que tienes la IP de tu servidor Linux (por ejemplo, 100.100.1.50) y el nombre del recurso compartido que definiste en el archivo smb.conf (por ejemplo, NombreCompartido), tienes varias formas de escribirlo en Windows[cite: 6]:

Opción A: Desde el Explorador de archivos (Barra de direcciones)

Abre cualquier carpeta o el Explorador de archivos y escribe directamente en la barra superior[cite: 6]:

\\100.100.1.50\NombreCompartido

(También puedes usar el nombre del host de Linux en lugar de la IP, por ejemplo: \\mi-servidor\NombreCompartido)[cite: 6].

Opción B: Usando la ventana "Ejecutar"

Es una de las formas más rápidas[cite: 6]:

  1. Presiona las teclas Windows + R[cite: 6].
  2. Escribe la ruta con barras invertidas dobles[cite: 6]: 
    \\100.100.1.50\NombreCompartido
  3. Presiona Enter[cite: 6].

Opción C:,|Recomendada| Mapear como Unidad de Red (para tenerla siempre visible)

  1. Abre el Explorador de archivos y haz clic en Este equipo[cite: 6].
  2. En la pestaña superior, selecciona Conectar a unidad de red[cite: 6].
  3. Elige una letra para la unidad (ej. Z:)[cite: 6].
  4. En la casilla Carpeta, escribe la ruta[cite: 6]: 
    \\100.100.1.50\NombreCompartido
  5. Marca la opción Conectar de nuevo al iniciar sesión si deseas que se guarde, introduce tus credenciales de samba cuando te las pida y haz clic en Finalizar[cite: 6].

Conclusión

Configurar la red local no requiere mucho trabajo[cite: 6]. usando samba , cualquier equipo Windows en la misma red se monta al instante[cite: 6].
